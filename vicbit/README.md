# VicBit - Clarity FT (SIP-010 compatible)

VicBit is a fungible token implemented in Clarity using Clarinet.

Features:
- SIP-010-compatible interface (name, symbol, decimals, balance, total-supply, transfer)
- Owner-only minting (configurable owner; set with one-time initialize)
- Holder self-burn

## Project layout
- `Clarinet.toml` – Clarinet project configuration
- `contracts/vicbit.clar` – VicBit token contract
- `tests/` – Place JS/TS tests here (generated by Clarinet)

## Dev quickstart

Prereqs: Clarinet installed and on PATH.

- Check contracts

```bash
clarinet check
```

- Launch REPL

```bash
clarinet repl
```

Then, in the REPL, you can try:

```clarity
;; One-time setup (sets the caller as owner)
(contract-call? .vicbit initialize)

;; Mint as owner
(contract-call? .vicbit mint u1000000 tx-sender)

;; Transfer tokens
(contract-call? .vicbit transfer u10000 'ST3J2GVMMM2R07ZFBJDWTYEYAR8FZH5WKDTFJ9AHA)

;; Check balance
(unwrap-panic (contract-call? .vicbit get-balance-of 'ST3J2GVMMM2R07ZFBJDWTYEYAR8FZH5WKDTFJ9AHA))
```

## SIP-010 endpoints
- `get-name () -> (response (string-ascii 32) uint)`
- `get-symbol () -> (response (string-ascii 32) uint)`
- `get-decimals () -> (response uint uint)`
- `get-balance-of (principal) -> (response uint uint)`
- `get-total-supply () -> (response uint uint)`
- `transfer (amount uint, recipient principal) -> (response bool uint)`

Extras:
- `initialize () -> (response bool uint)` (one-time owner setup)
- `set-owner (new-owner principal) -> (response bool uint)` (only current owner)
- `mint (amount uint, recipient principal) -> (response bool uint)` (owner-only)
- `burn (amount uint) -> (response bool uint)`

## Deployment notes
- The contract owner is the account that publishes the contract; only the owner can mint.
- Decimals are set to `6` (i.e., 1 VICBIT = 1_000_000 base units).
